## 🚀 Proyectos destacados

### 🛒 Funko Store

E-commerce desarrollado con **React + Vite** para simular el flujo de compra de una tienda de figuras Funko.

**Características principales:**
- Catálogo de productos
- Carrito de compras
- Persistencia con `localStorage`
- Manejo de estado con Context API
- Navegación con React Router
- Checkout simulado
- Diseño responsive
- Despliegue automático mediante GitHub Actions

**Tecnologías:** React · JavaScript · Vite · CSS · React Router
